# Wonderlust 🏡

Wonderlust is an Airbnb-like full stack web application built with a strong
focus on backend development, RESTful APIs, and secure authentication.

---

## 🚀 Features
- User authentication & authorization
- Property listings with full CRUD operations
- Reviews and ratings system
- Secure routes using middleware
- Centralized error handling
- Server-side rendering with EJS

---

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap
- JavaScript

---

## 🧠 Backend Concepts Used
- MVC Architecture
- RESTful APIs
- Authentication & Authorization
- Middleware
- Error Handling
- MongoDB relationships (Listings & Reviews)

---
## 📂 Project Structure
routes/ → Application routes
models/ → Mongoose schemas
views/ → EJS templates
utils/ → Custom error & async wrapper
public/ → Static assets (CSS, JS)


---

## 🎯 Purpose of This Project
This project was built to strengthen backend development skills,
understand real-world application architecture,
and prepare for backend / full-stack interviews.
